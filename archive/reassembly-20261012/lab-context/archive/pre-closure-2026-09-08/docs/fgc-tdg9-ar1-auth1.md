## Exact diagnostic

Each of the eighteen frozen owned-state channels supplies one outer, two
medium, and four fine binary64 Hermite segments. Both evaluators independently:

1. convert every built-in binary64 endpoint, right-hand side, and width to its
   exact dyadic rational with `as_integer_ratio()`;
2. reconstruct the cubic Hermite coefficients;
3. restrict outer and medium cubics to the required child intervals;
4. form the exact difference cubics;
5. enclose the generally algebraic suprema `D01` and `D12` with rational
   isolating intervals; and
6. apply the unchanged two-sided comparison.

The per-channel terminal classes are:

```text
exact_zero
sufficient_contraction_pass
sufficient_contraction_failure
resource_inconclusive
```

`exact_zero` is an exact discrete statement, not an observed-order pass. It
means both reconstructed exact-difference suprema vanish, so that channel
cannot be the obstruction that caused the legacy outward enclosure to reject
the proposal. At aggregate level it therefore maps directly to the
legacy-enclosure-owner side; a mixture of `exact_zero` and independently
certified sufficient-contraction passes has the same aggregate meaning.

A pass is certified only when

```text
8 * U12^2 <= L01^2.
```

A failure is certified only by the strict reverse enclosure

```text
8 * L12^2 > U01^2.
```

Merely negating the sufficient-pass inequality is not a certified failure.
Exact equality belongs to the pass side; if bounded interval refinement cannot
prove equality or either strict alternative, the channel is inconclusive.

The two evaluator implementations must independently reconstruct the same
coefficient-stream identity and agree on every completed classification. A
replay mismatch, coefficient-stream mismatch, evaluator disagreement,
malformed input, or authority/provenance drift is an invalid implementation
terminal rather than an arithmetic result.

## Outcome boundary

The later result may return exactly one scientific classification:

```text

legacy_enclosure_not_sole_owner_on_frozen_samples
arithmetic_discriminator_inconclusive
```

An authority, replay, or implementation failure remains separate:

```text

```

Even the strongest first classification says only that the legacy enclosure
owned nonadmission on the three frozen replay samples. It is not a universal
arithmetic-floor theorem and does not prove that every later width would pass.
An all-`exact_zero` result reaches that classification because zero exact
discrete difference cannot be the obstruction, not because an observed order
was measured or passed.
Aggregate precedence is fail-closed and explicit: any independently certified
`sufficient_contraction_failure` determines
`legacy_enclosure_not_sole_owner_on_frozen_samples`, even when another channel
is `resource_inconclusive`. The aggregate
`arithmetic_discriminator_inconclusive` class applies only when no certified
failure exists.
The second classification identifies at least one exact discrete/Hermite
obstruction on the frozen samples; it is not a physical obstruction. The
third says the bounded experiment lacked enough arithmetic resolution.

This authority therefore earns none of the following: an execution result,
