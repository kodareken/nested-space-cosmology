# Evolved-state control of the owned common-kernel pairing

This check applies the existing common KS kernel owner to saved evolved
source columns. Source frequencies E and reference Weyl momenta k are
integrated separately into the same equal-time kernel. Both declarations
remain `control_only`; neither quadrature is a complete spectrum.

The physical columns and their actual axial derivatives are taken at stored
points symmetric about the same incoming midpoint. Three constant splits
are used: zero and two nonzero separations. The homogeneous reference uses
the saved jointly evolved reference amplitudes from the same upstream
columns. No state, source or history evolution is rerun.

The reference symbol is evaluated on an independent24-node k quadrature on
`[-4,4]`, for the actual incoming jets and the reference jets. At zero split,
the common-kernel contraction must reproduce the same finite raw source
change minus the same finite reference-symbol change. This is an identity
check; the partial reference quadrature is not substituted for the certified
local/reference coefficients.

The compact test variations have a unit plateau around the probe and vanish
before the axial-cell ends. The vertex is therefore the actual endpoint
vertex at all three sampled splits. The finite-k band remainder is not set
to zero, and the bulk unweighted cancellation already used by the certified
coefficients is not reopened.

The nonzero-split differences show the numerical relation that the final
ordered-limit proof must control. They are not convergence bounds: the
physical E tail, reference k tail, coincidence remainder and any finite
cutoff/limit exchange remain explicit. In particular, an auxiliary bound on
`C-P` in canonical k is not automatically the error of truncating the
original input-energy source. No new Gamma_rest or physical cutoff is
introduced. The local incoming gate remains OPEN.
