# Code of Conduct

Scientific disagreement is expected and useful. Participants must criticize claims, methods, evidence, and reasoning without attacking people. Good-faith counterexamples, failed replications, and negative results receive the same respect as supportive results.

Harassment, threats, discrimination, doxxing, or repeated personal abuse are not accepted. Maintainers may remove contributions or participation that violate these expectations.

The project’s governing norm is simple: nobody is a guardian of a conclusion. Everyone is responsible for making the path to the truth shorter.
