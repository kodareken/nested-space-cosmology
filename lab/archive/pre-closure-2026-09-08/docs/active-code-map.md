# Active code and authority map

## Purpose

This page is the short, current routing surface for Recursive Horizons. It
answers four questions:

1. Which record owns a statement?
2. What is the current execution frontier?
3. Which compact checks are ordinary and safe to run?
4. Which operations remain closed?

It is not another artifact chronicle. Historical detail belongs to Git, the
claim ledger, the result owners, and the changelog.

## Authority order

`AGENTS.md` is the user-authored creative working-hypothesis orientation. It
is not evidence and does not authorize a candidate, rewrite a compact result,
or override a failed executable gate.

`PLAN.md` is the current implementation and finish-line execution plan. It
routes Phase −1 cleanup and remaining FGC-2-SF1 work; it is not a substitute
for the claim ledger.

When scientific statements appear to disagree, use this order and preserve
the narrower claim:

1. `AGENTS.md` — creative research orientation.
2. [Claim ledger](claim-ledger.md) — atomic scientific claims, evidence
   states, and falsifiers.
3. [Research roadmap](research-roadmap.md) — forward dependency/execution
   plan.
4. [FGC runtime matrix](fgc-runtime-matrix.md) — runtime, environment,
   arithmetic, and raw/compact ownership.
5. [Results index](../results/README.md) — compact machine-result index.
6. [Versioned prospectus](../paper/recursive-horizons.md) — the scientific
   programme, not a live development log.
7. [Project README](../README.md) — short project entrypoint and routing page
   only.

The generated [`artifact catalog`](../configs/fgc/artifact-catalog.json) is
validated routing and discovery for artifact IDs, owners, configs, compact
hashes, predecessors, and closed operations. It is not a higher scientific
authority than the order above. This page is a current-command map, not a
chronicle.

Old compact results and authority commits remain immutable evidence. A later
artifact can supersede their *authorization or interpretation* without
rewriting their bytes.
