# Security

This repository contains offline scientific calculation code and requires no
credentials, network services, or privileged execution.

If you find a vulnerability that could affect people reproducing the work,
report it privately through GitHub's **Security → Report a vulnerability**
interface. Do not place credentials, private datasets, or host-specific paths
in an issue, pull request, result record, or Actions log.

Scientific disagreements and reproducibility failures are not security issues;
open those through the ordinary issue tracker with the smallest reproducible
example and the affected artifact ID.
